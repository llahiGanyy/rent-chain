Rent-Chain
Rent-Chain is a Clarity smart contract that enables decentralized rental agreements for NFTs and tokens on the Stacks blockchain.
It ensures fairness with escrowed assets, time tracking, and transparent logs.

Features
Create rental offers with asset, duration, and rent price
Tenants accept and pay rent on-chain
Assets held in escrow during rental period
Automatic return of asset to owner after expiration
On-chain transparency with event logs

Technical Overview
Language: Clarity
Core Functions:
create-offer – define rental terms
accept-offer – tenant accepts and pays rent
end-rental – conclude rental and return asset
get-rental-info – fetch details of active rentals
